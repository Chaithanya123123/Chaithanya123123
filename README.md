# Hi, I'm Chaithanya

I build AI systems that show their evidence: retrieval with checkable citations, agents whose risky decisions stay in plain code, and voice-first interfaces.

**Interests:** RAG · LLM agents · graph retrieval · voice interfaces · LLM evaluation and reliability

## Selected projects

| Project | What it does | Built with |
|---|---|---|
| [**DocPilot**](https://github.com/Chaithanya123123/DocPilot) | Ask a PDF questions by voice or text. Every citation is validated on the server and highlighted on the exact page. 24 offline tests. | FastAPI, FAISS + BM25, Mistral, React |
| [**DisputeDesk**](https://github.com/Chaithanya123123/Dispute_desk_paypal) | Prepares PayPal dispute responses. The LLM proposes; deterministic risk and policy code decides. 30 automated checks. | FastAPI, Next.js, PayPal API |
| [**TraceMind**](https://github.com/Chaithanya123123/Graphrag-memory) | Research agent over a paper graph: citation lineage, contradictions and memory, with the Cypher query shown beside each answer. | FalkorDB, FastAPI, Cytoscape.js |
| [**AgriAdvisor AI**](https://github.com/Chaithanya123123/NXT_Wave) | Multilingual farm assistant that combines live weather, market prices, soil data and crop guidance. Two-person buildathon project. | LangGraph, Gemini, ChromaDB, React |
